# Phase Terminology Crosswalk

This package uses the current authoritative nine-phase methodology terminology. Some
historical raw evidence (assessment notes, prior artifact drafts) predates a terminology
update and uses earlier phase names. Historical raw evidence is not rewritten; this
crosswalk documents the correspondence for any authored derivative material in this package.

| Phase | Current terminology | Notes |
|---:|---|---|
| 4 | Firmware, Embedded System, and Supply Chain Analysis | Earlier drafts in this project used "Firmware, System Analysis & Supply Chain" or similar. Same phase, updated name. |
| 7 | Vulnerability Analysis and Tiered Controlled Validation | Earlier drafts used "Vulnerability Analysis and Controlled Exploitation." Same phase, updated name; "Tiered" reflects the project's current validation-tier framework. |

All other phase names in this package (0, 1, 2, 3, 5, 6, 8) are unchanged from earlier
drafts. See `documentation/methodology/` in the main repository for the authoritative
nine-phase definition; that document is not duplicated here since this package is meant to
stand alone without depending on it.
